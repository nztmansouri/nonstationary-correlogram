# Name
 
This toolbox reproduces methods and figures from: 

Tajik-Mansouri Z, Dion JP Jr, Escabí MA, Stevenson IH. Parametric models for predicting nonstationary spike-spike correlations with local field potentials. J Neural Eng. 2026 Apr 29;23(2). doi: 10.1088/1741-2552/ae5ea5. PMID: 41974133.

see Figure1.m demo, Figure3.m, Figure6.m, Figure 7.m and Figure8.m for detailed examples using example data from the [Allen Institute - Visual Coding Neuropixels Dataset](https://portal.brain-map.org/explore/circuits).

# Dependencies

The code here uses several other toolboxes:

[mullerlab/wave-matlab](https://github.com/mullerlab/wave-matlab)
[mullerlab/generalized-phase](https://github.com/mullerlab/generalized-phase)
[circstats toolbox](https://www.mathworks.com/matlabcentral/fileexchange/10676-circular-statistics-toolbox-directional-statistics)
[The Large Time-Frequency Analysis Toolbox(LTFAT): Morlet wavelet](https://ltfat.org/doc/filterbank/).
