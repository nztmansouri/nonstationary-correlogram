# Name
 
This toolbox reproduces methods and figures from...

Tajik Mansouri et al. (2025) Parametric models for predicting nonstationary spike-spike correlations with local field potentials.

see demo_simulation.m, demo_longtime.m, demo_shorttime.m for detailed examples using example data from the [Allen Institute - Visual Coding Neuropixels Dataset](https://portal.brain-map.org/explore/circuits).

# Dependencies

The code here uses several other toolboxes...

[mullerlab/wave-matlab](https://github.com/mullerlab/wave-matlab)
[mullerlab/generalized-phase](https://github.com/mullerlab/generalized-phase)
[circstats toolbox](https://www.mathworks.com/matlabcentral/fileexchange/10676-circular-statistics-toolbox-directional-statistics)
